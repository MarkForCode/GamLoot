# Agent Automation

This directory contains tool-neutral automation and adapter guidance for AI-assisted development.

Canonical collaboration rules live in `docs/ai/`. Files here should provide runnable helpers, not duplicate policy.

## Contents

| Path | Purpose |
| --- | --- |
| `hooks/` | Safe validation hooks for agents, humans, and CI experiments. |

## Rule

If a hook encodes a workflow expectation, document that expectation in `docs/ai/hooks.md` or `docs/workflow/`.
